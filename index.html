Install

Narvo is plain Markdown in a folder. Every agent below reads skills from a directory — the install is a git clone into the right place. Pick your agent.

The library

Every card is a full reference document: color roles, typography rules, component CSS, layout, elevation, do's and don'ts, and responsive behavior. Open one to read the tokens, copy the Markdown, or install that single file.

No system matches that.

Using it

Once installed, name a product as a style target and the agent loads the matching reference.

Ask for a look by name

> Build the pricing page. Use the Linear system from narvo.

Or describe the character and let it choose

> I want something warm and editorial, not another dark SaaS dashboard.
>   Pick a system from narvo and show me two options.

Or pull specific tokens into an existing project

> Read narvo's stripe reference and emit its palette and type scale
>   as CSS custom properties in src/styles/tokens.css
